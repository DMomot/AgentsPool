1️⃣  ВОЙДИ В RAILWAY
    → Login через GitHub
    → Авторизуй доступ к репозиториям

2️⃣  СОЗДАЙ ПРОЕКТ
    → New Project
    → Deploy from GitHub repo
    → Выбери: AgentsPool

3️⃣  ДОБАВЬ БАЗУ ДАННЫХ
    → + New
    → Database → Add PostgreSQL
    → Готово! (автоматически)

4️⃣  НАСТРОЙ BACKEND
    → + New → GitHub Repo → AgentsPool
    → Settings → Root Directory: backend
    → Variables:
       • DATABASE_URL = ${{Postgres.DATABASE_URL}}
       • SECRET_KEY = agentspool-production-secret-key-2024
       • PORT = 8000
    → Дождись деплоя (2-3 мин)
    → СКОПИРУЙ Backend URL

5️⃣  НАСТРОЙ FRONTEND
    → + New → GitHub Repo → AgentsPool
    → Settings → Root Directory: frontend
    → Variables:
       • NEXT_PUBLIC_API_URL = [Backend URL из шага 4]
    → Дождись деплоя (3-4 мин)
    → СКОПИРУЙ Frontend URL

6️⃣  ОБНОВИ CORS
    → Открой Backend Service
    → Variables → добавь:
       • FRONTEND_URL = [Frontend URL из шага 5]

7️⃣  ИМПОРТ БД (в этом терминале):
    railway login
    railway link
    railway run psql \$DATABASE_URL < database_backup_20251007_151635.sql
